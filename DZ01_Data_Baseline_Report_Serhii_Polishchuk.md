| Поле | Зміст |
|------|-------|

| **Як знайшли** | Підрахунок кількості боксів по класах у train-split (скрипт аудиту). |

| **Дія** | Розглянути class-balanced sampling, weighted loss або oversampling рідкісних класів. |
| **Перевірка** | Порівняти per-class AP до і після застосування балансування. |

### Знахідка 2. Велика частка дрібних об’єктів

| Поле | Зміст |

| **Дія** | Використовувати моделі, оптимізовані під small objects (наприклад, з FPN / BiFPN, вищим input resolution, або specialized small-object detectors). |
| **Перевірка** | Виміряти AP для об’єктів різних розмірів (small / medium / large) за COCO-стилем. |

## 4. Розбиття (Splits) і перевірка leakage

### Офіційні splits
Використано офіційний поділ VisDrone2019-DET:
- **train** — 6 471 зображень
- **val** — 548 зображень
- **test-dev** — 1 610 зображень (з доступними анотаціями)

Офіційний split збережено без змін.

### Перевірка на leakage

**Точні дублікати (MD5):**
- Між train і val **точних дублікатів не знайдено**.
- Знайдено кілька дублікатів *всередині* train та *всередині* val (не впливають на leakage між splits).

**Майже однакові зображення (average hash, Hamming ≤ 5):**
- На вибірці 300 зображень train + усі 548 val знайдено **36 пар** з високою схожістю.

### Обмеження перевірок
- Пошук near-duplicates виконувався на **вибірці** 300 train-зображень (повний pairwise search на 6.5k зображень є обчислювально дорогим).
- Не перевірялася семантична схожість сцен (однакові локації, зняті під різним кутом).
- VisDrone-DET складається переважно зі статичних зображень, тому ризик leakage через сусідні кадри відео менший, ніж у відео-датасетах.

### Обґрунтування
Офіційний split VisDrone залишається прийнятним для baseline.  
Наявність near-duplicates на вибірці вказує на потенційний ризик, який варто моніторити. Для фінальних експериментів можна додатково провести більш повний near-duplicate аналіз або використати GroupKFold за локацією (якщо метадані доступні).

## 5. Domain Shift

VisDrone2019-DET зібраний дронами в **китайських містах** за різних погодних і освітлювальних умов.

### Потенційні розбіжності з майбутнім застосуванням (DefenceTech / security сценарій):

| Аспект                    | VisDrone                          | Можливий цільовий сценарій              | Ризик |
|---------------------------|-----------------------------------|-----------------------------------------|-------|
| Географія                 | Китайські міста                   | Європа / Близький Схід / Африка         | Високий |
| Типи об’єктів             | Цивільний транспорт, пішоходи     | Військова техніка, специфічні ТЗ        | Високий |
| Висота / кут зйомки       | Типові висоти дронів VisDrone     | Інша висота / FOV / роздільна здатність | Середній |
| Освітлення                | День + різні умови                | Ніч, тепловізор, low-light              | Високий |
| Щільність і occlusion     | Висока                            | Може бути іншою                         | Середній |
| Камуфляж / маскування     | Відсутній                         | Може бути присутнім                     | Високий |

### Невідомі параметри (потрібно зафіксувати пізніше)
- Точна модель камери та висота польоту цільової системи
- Очікуваний розподіл розмірів об’єктів у цільовому домені
- Наявність класів, яких немає у VisDrone (наприклад, танки, БПЛА, специфічна техніка)

**Висновок:** результати, отримані на VisDrone, **не гарантують** перенесення на інший географічний регіон, інший тип сенсора або військовий сценарій без додаткової адаптації / донавчання.

## 6. Augmentation

### Запропоновані перетворення

| Аугментація              | Параметри (початкові)      | Мета                              | Ризики |
|--------------------------|----------------------------|-----------------------------------|--------|
| Horizontal Flip          | p = 0.5                    | Збільшення різноманітності        | Низький |
| Random Brightness/Contrast | limit ±20–30%            | Різні умови освітлення            | Середній (надмірне спотворення) |
| Hue / Saturation shift   | невеликі значення          | Різний колір транспорту / одягу   | Низький |
| Random Scale / Resize    | scale 0.7–1.3              | Різні розміри об’єктів            | Середній |
| Mosaic / MixUp (опційно) | —                          | Щільні сцени + small objects      | Високий (може спотворити геометрію) |
| Motion Blur / Gaussian Blur | невелика ймовірність   | Імітація руху дрона               | Середній |
| Random Crop (збереження об’єктів) | —                   | Фокус на дрібних об’єктах         | Середній |

### Рекомендації
- Через велику кількість **дрібних об’єктів** — уникати занадто агресивного downscale.
- Через **високу щільність** — Mosaic може бути корисним, але потребує обережного налаштування.
- Для боротьби з **class imbalance** — можна комбінувати з class-aware sampling.
- Аугментації, що сильно змінюють геометрію (сильний shear, extreme perspective), краще застосовувати обережно або не застосовувати на першому етапі.

### Ризики
Надмірні аугментації можуть:
- Зробити дрібні об’єкти ще меншими або невидимими
- Порушити реалістичність сцен з дрона
- Погіршити якість на рідкісних класах

Рекомендується починати з помірного набору (Flip + ColorJitter + легке Scale) і додавати складніші перетворення після baseline.

## Висновок

VisDrone2019-DET є якісним і широко використовуваним бенчмарком для детекції з дрона.  
Аудит показав:

1. Сильний дисбаланс класів
2. Велику частку дрібних об’єктів
3. Високу щільність сцен і значну occlusion
4. Відсутність точних дублікатів між train і val (але наявність near-duplicates на вибірці)
5. Потенційно суттєвий domain shift при переносі на інші регіони / сенсори / військові сценарії

Датасет **готовий** до використання для baseline за умови врахування зазначених особливостей при виборі моделі, loss-функції, аугментацій та стратегії оцінки.
